// What v43 fixes

THE BLACK-SCREEN SYNTAX BUG: the v42 recorder patch left two orphan chunks of recorder code sitting at the TOP LEVEL of the script (outside any function). Their bare return; statements are illegal there, so the whole script died at boot with "illegal return statement" — black canvas, dead buttons. v43 deletes both orphan chunks; all recorder logic now lives ONLY inside startRec() and the two record buttons.



// What v42 fixed (html2app edition)

html2app wraps pages in a Flutter WebView whose bridge has storage/vibration/ads but no file picker — that's why OPEN did nothing with zero log lines. v42:

• OPEN is now a real tap target (a transparent file input over the button) so it works in any shell that DOES support uploads, including plain browsers.

• LINK ✦ loads images from a pasted URL or base64/data-URL — the path that works inside html2app.

• If a first OPEN tap produces no picker, the Debug Log says so and points at LINK.

• Gallery-straight picking requires a wrapper whose WebView implements file upload, or the Android Studio project from earlier builds.



// Pipeline

SOURCE → ADJUST → COLOR LAB (pre) → DITHER ENGINE → COLOR LAB (post) → OUTPUT MODE → FX STACK → FEEDBACK/TRAILS.



// Performance Tips

• Frame time over ~33ms? Drop PIXEL size first, then MAX RES.

• FEEDBACK and TRAILS each cost one extra canvas pass.

• BREAKER auto-pauses LIVE if the frame budget collapses.
